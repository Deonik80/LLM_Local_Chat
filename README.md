Ключевые возможности:
Мультимодальность и работа с файлами: Поддерживает отправку изображений и автоматически извлекает текст из документов форматов .pdf, .docx, .xlsx, .csv, .txt, .py, .md для контекста модели. Если модель не поддерживает Vision (ошибка 400), интерфейс предложит отправить запрос повторно без картинок.
Гибкое управление контекстом: Позволяет настраивать параметры генерации (temperature, top_p, max_tokens, seed, context length). Доступна функция сжатия истории (саммари диалога) для экономии токенов и предотвращения переполнения контекста.
Профили и пресеты: Поддерживает создание пользовательских системных промптов и пресетов. Позволяет сохранять «Профили связок» (комбинация конкретной модели, промпта и параметров) для быстрого переключения задач.
Интеграция окружения: Возможность загрузки файлов requirements.txt и .env для автоматической передачи структуры вашего проекта в System Prompt модели.
Голосовые функции: Реализован голосовой ввод сообщений (STT) и озвучивание ответов ассистента (TTS).
Удобство интерфейса: Мультиязычность (RU/EN), смена тем оформления, масштабирование шрифта, полнотекстовый поиск по чату, оценка ответов, сохранение альтернативных вариантов генерации и экспорт диалогов в HTML, Markdown или JSON.
Безопасное завершение: При закрытии приложения автоматически выгружает модель из памяти видеокарты и сохраняет геометрию окна.
